Minha Biblioteca em C

Projeto desenvolvido na linguagem C, utilizando funções organizadas em arquivos separados.

Funcionalidades

- Cálculo da sequência de Fibonacci.
- Verificação de números pares.
- Verificação de números positivos.
- Cálculo de potência.
- Cálculo da média de duas notas.
- Cálculo de fatorial.

Arquivos do projeto

- "main.c": programa principal.
- "minhaLib.h": declarações das funções.
- "minhaLib.c": implementação das funções.

Tecnologias utilizadas

- Linguagem C
- OnlineGDB
- GitHub

Projeto desenvolvido para praticar programação e organização de bibliotecas em C.
